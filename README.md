# Rakesh Reddy — portfolio

A static portfolio covering selected projects, experience, education, research, and ways to get in touch.

The site is built from `index.html`, `style.css`, and the images in `assets/`; it does not require a build step. Run a local preview with `python3 -m http.server` from this directory. Netlify publishes the `rakesh-myportfolio` branch at https://sairakeshreddy.netlify.app/.

The Housie visual is taken from a concept demonstration using synthetic examples. Prior versions of the portfolio are available in Git history.
