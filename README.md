# Sai Rakesh Reddy - Data Scientist Portfolio

A portfolio website inspired by the Comet website design (comet.perplexity.ai), customized to showcase data science expertise and projects.

## Features

### 🎨 Visual Design
- **Dark Cosmic Theme**: Deep space aesthetic with gradient effects
- **Modern Typography**: Inter font with special highlight and underline effects
- **Responsive Design**: Fully responsive layout that works on all devices
- **Smooth Animations**: CSS animations and transitions for enhanced user experience

### 🔧 Interactive Elements
- **FAQ Accordion**: Expandable FAQ section with smooth animations
- **Planet Selection**: Interactive solar system with detailed planet information
- **Smooth Scrolling**: Navigation links with smooth scrolling behavior
- **Custom Cursor**: Interactive cursor effects (on desktop)
- **Keyboard Navigation**: Full keyboard accessibility support

### 📱 Responsive Features
- Mobile-first design approach
- Tablet and desktop optimizations
- Touch-friendly interface elements
- Optimized typography scaling

## Key Sections

1. **Header**: Fixed navigation with blur effect
2. **Hero Section**: Professional introduction with CTA buttons
3. **About**: Detailed background and approach to data science
4. **Core Expertise**: Three main areas of specialization with featured project cards
5. **Projects**: Interactive project showcase with detailed descriptions
6. **Experience**: Background, education, and work approach
7. **Footer**: Professional links and contact information

## Interactive Features

### Experience Accordion
- Click on any experience question to expand/collapse
- Only one section can be open at a time
- Keyboard navigation support with arrow keys

### Project Showcase
- Click on any project area to view detailed information
- Comprehensive descriptions and impact metrics for each specialty
- Smooth transitions between project data
- Keyboard navigation with left/right arrow keys

### Navigation
- Smooth scrolling to sections
- Fixed header that changes opacity on scroll
- Mobile-friendly navigation menu
- Functional CTA buttons linking to LinkedIn, GitHub, and email

## Development Notes

The website uses modern CSS features including:
- CSS Custom Properties (variables)
- CSS Grid and Flexbox
- CSS Animations and Transitions
- Backdrop filters

JavaScript features:
- ES6+ syntax
- Intersection Observer API
- Modern event handling
- Accessibility features

## How to Use

1. Open `index.html` in any modern web browser
2. Navigate through sections using the header menu
3. Interact with the Experience section and Project showcase
4. Click on CTA buttons to visit LinkedIn, GitHub, or send an email
5. Experience the smooth animations and responsive design
