# Portfolio Icons Guide

## Current Icon Status
Currently using Unicode emojis and symbols for visual consistency. For production, consider replacing with professional SVG/PNG icons.

## Recommended Icon Sources

### Free Icon Sources
1. **Feather Icons** (https://feathericons.com/) - Clean, minimal SVG icons
2. **Heroicons** (https://heroicons.com/) - Beautiful hand-crafted SVG icons
3. **Lucide** (https://lucide.dev/) - Simple and clean icons
4. **Tabler Icons** (https://tabler-icons.io/) - Over 3000+ free SVG icons

### Premium Icon Sources
1. **Font Awesome Pro** (https://fontawesome.com/pro) - Comprehensive icon library
2. **Iconify** (https://iconify.design/) - Unified icons framework
3. **Streamline Icons** (https://streamlineicons.com/) - Premium icon sets

### Technology-Specific Icons
1. **Simple Icons** (https://simpleicons.org/) - SVG icons for popular brands
2. **DevIcons** (https://devicons.github.io/devicon/) - Programming language icons

## Usage Guidelines
1. Use consistent icon sizes (24px recommended)
2. Maintain consistent visual weight
3. Use SVG format for scalability
4. Ensure accessibility with alt text
5. Consider dark/light mode variations

## Implementation Example
```html
<img src="assets/icons/python.svg" alt="Python" class="tech-icon">
```

```css
.tech-icon {
    width: 24px;
    height: 24px;
    display: inline-block;
    vertical-align: middle;
}
```
